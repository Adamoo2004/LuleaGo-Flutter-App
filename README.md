# LuleåGo

Detta är en enkel Flutter-prototyp för mobilitet i Luleå för studenter.

## Kom igång

1. Installera Flutter SDK och Android Studio.
2. Skapa en Android-emulator i Android Studio.
3. I terminalen:
   - `flutter doctor`
   - `flutter pub get`
   - `flutter run`

## Struktur

- `lib/main.dart` – appens huvudfil med navigation och state.
- `lib/models/trip.dart` – datamodell för resor.
- `lib/screens/` – de fem sidorna i appen.

## Första steg

Detta är bara grundstrukturen. Vi bygger appen steg för steg.
